这个后台不连服务器：用你的 GitHub Token（需 repo 权限）直接把改动提交到 grainshun.github.io 仓库，实现永久保存。
不会生成 Token？打开 github.com/settings/tokens → Generate new token(classic) → 只勾 repo → 复制即可。 Token 只存在你浏览器里，不会上传任何第三方。
